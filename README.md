# FE000000 Mobile

Dan Simon 的 [FE000000](https://github.com/dan-simon/misc/tree/master/fe000000) 的独立界面改版。保留原游戏的计算、进度、购买、离线模拟和存档格式。

## 运行

没有运行时框架或安装依赖的要求。可以直接打开 `index.html`；建议用固定地址的静态服务器，让浏览器稳定保存进度：

```sh
cd fe000000-mobile
python3 -m http.server 8080 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:8080`。部署时上传整个目录中的静态文件即可，不需要 Node 服务。

## 从原版迁移

在原游戏的 Options 导出存档，再在新版 Options 导入。不同域名、端口和浏览器拥有独立的本地存储，不会自动取得你在原站上的进度。该项目没有读取你的个人存档。

## 界面

- 自动适应手机和桌面宽度，没有设备切换开关。
- 深色、浅色、跟随系统；顶栏快速切换，Options 中可选择跟随系统。
- 底部切换主要分组，顶部切换当前组内页面；All 打开按原有分组排列的已解锁页面。选择页面和功能组时保留滚动位置及组内选择。
- 生成器使用紧凑的双行布局，买 1／买最大模式统一选择，Max all 固定在靠近底部的位置。
- 原有自动购买开关保留；高级说明、升级和其他控制位于生成器页的 Details 中。基础重置操作保留，其他重置和全局状态位于顶栏 Resets。
- 挑战、自动购买和设置按页面类型重新排版；Studies 在手机上使用两列。必须保持表格关系的内容采用局部横向滚动，不缩放整个页面。
- 点击问号和成就说明可打开详细解释；菜单与解释面板支持键盘及 Escape。
- 解锁和显示判断沿用原版，不预先创建可见的未解锁导航入口。

8 个生成器使用 52px 基础行高，购买按钮保留 44px 触控高度。实际可见行数受屏高、浏览器工具栏、长数值、已开启的自动购买和挑战状态影响；更小的屏幕允许滚动，Max all 仍保持可访问。

原界面可通过 `?legacy=1` 打开，用于对照和排查问题。

## 构建与测试

```sh
node compile.js
npm install --ignore-scripts
npm test
```

`index-template.html` 是页面源文件，`compile.js` 生成 `index.html` 和 `js/update-display.js`。不要只改生成的 HTML。

运行游戏不需要 `node_modules`。唯一开发依赖 LinkeDOM 用于在隔离的 DOM 环境中执行原游戏及界面适配器，检查：

- 所有本地资源与原显示器绑定节点完整、ID 不重复；
- 新存档不会展示锁定页面；
- 单买、买最大调用原购买逻辑；
- Complexity 以内 22 个已解锁页面的挂载与分组切换；
- 明暗主题、存档序列化和重新导入；
- 原界面回退。

这些是 DOM／游戏逻辑集成测试，不是浏览器布局测试。当前环境未完成真实手机和桌面浏览器的视觉验收；发布后的验收步骤见 `QA.md`。
